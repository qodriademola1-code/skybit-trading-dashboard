# SkyBit Enterprise – Trading & Wallet Dashboard

SkyBit Enterprise is a responsive, state-heavy cryptocurrency trading portal designed to simulate real-world financial dashboard interactions. This project focuses deeply on frontend state persistence, secure user flows, and modular JavaScript architecture.

## 🚀 Live Demo
Experience the live application here: [SkyBit Enterprise Live](https://skybitenterprise.netlify.app/)

## 🛠️ Tech Stack
* **Core Structure:** Semantic HTML5
* **Styling & Layout:** CSS3 (Flexbox, Custom Grid Matrices, Modern Translucent Glassmorphism)
* **Application Logic:** Vanilla JavaScript (ES6+)
* **Session Persistence:** Browser `localStorage` API

## ⚡ Key Engineering Features
* **Authentication Listeners:** Engineered dynamic user login and registration scripts that securely validate inputs and track active authorization states.
* **Wallet & Withdrawal Logic:** Programmed a modular bank withdrawal management system utilizing custom DOM event listeners to handle financial requests seamlessly.
* **Persistent User Sessions:** Integrated local storage mechanisms to save and retrieve active user objects, maintaining user data across page refreshes.
* **Data-Driven UI:** Configured dynamic layout components to cleanly display simulated asset balances, trading metrics, and historical transaction logs.
